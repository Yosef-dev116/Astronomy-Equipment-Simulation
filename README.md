# Astronomy Equipment Store Simulation

A Python-based simulation of an astronomy equipment store.  
This project demonstrates object-oriented programming, inventory management, and basic simulation logic.

## 🧩 Overview

This program simulates:
- Adding products to inventory  
- Tracking stock and sales  
- Interactions with simulated customers  

It was built as a learning project to practice Python classes, program flow, and user input handling.

## 🛠 Technologies Used
- Python
